# GARWEVIA — image prompts for the website

Generate each image, save it with the **file name** shown, and send it over (or drop it in `public/images/`). I will place each one in the section listed.

**Rules for every image (paste at the end of each prompt):**

> Photorealistic commercial photography, soft natural daylight, clean premium catalogue look, colour palette of deep navy, warm sand, off-white and muted earth tones, no logos, no brand names, no readable text, no watermark, high detail, sharp focus.

Prefer **products, materials and close-ups of hands**. Avoid crowded factory floors and posed workers — buyers want to see the product and the control, not the labour.
