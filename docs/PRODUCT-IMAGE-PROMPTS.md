# GARWEVIA — product image prompts

Save each image in **public/images/products/** with the exact file name shown (`.webp`, `.jpg` or `.png`). It appears on the website automatically — no code change needed.

**Style line — add to the end of every prompt:**

> Photorealistic e-commerce product photograph, flat lay on a warm light-stone surface, soft natural daylight from the top left, gentle shadows, centred with generous margin, colour palette of navy, oatmeal, olive, off-white and terracotta, no logos, no brand names, no readable text, no people, no mannequin, high detail fabric texture, square 1:1, 1600×1600.

Tip: generate one category at a time in the same session so the surface, light and colours stay consistent.
